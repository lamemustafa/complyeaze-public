# ComplyEaze public fonts

The ComplyEaze public site self-hosts its type without a runtime Google Fonts
request. Each file is a WOFF2 subset (Basic Latin, Latin-1, common punctuation,
arrows and the Indian rupee sign U+20B9) made with `fonttools pyftsubset`.

- Anek Latin variable font (weight 100-800, width 75-125) by Ek Type and its
  license: [google/fonts/ofl/aneklatin](https://github.com/google/fonts/tree/main/ofl/aneklatin)
- Courier Prime Regular and Bold by Alan Dague-Greene and its license:
  [google/fonts/ofl/courierprime](https://github.com/google/fonts/tree/main/ofl/courierprime)

Both directories contain the upstream `OFL.txt` distributed with the font.
The files were retrieved from the official Google Fonts repository on
2026-09-23.
